# Workout Log

Personal Android app for home-gym workouts.

- **Next**: which body areas are due today, and for each, the movements you haven't done lately.
  Tick what you'll do, then tap Log.
- **Log**: sets, reps and weight for each movement (pre-filled from last time), extra lines for
  different weights, a note per movement, and workout notes. Log an area only when you didn't track movements.
- **History**: every day logged, with delete for a day or a single movement.
- **Exercises**: add, rename, move or delete movements; set how often each area should come up;
  save or restore a backup file.

Build and install: plug in the phone and double-click `install.bat`.
